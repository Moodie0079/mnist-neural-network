# MNIST Neural Network in C

Handwritten digit classifier written from scratch in C.

## Setup

Download the dataset from [Kaggle](https://www.kaggle.com/datasets/hojjatk/mnist-dataset/data) and put the 4 idx files in a folder called `mnist-dataset/`.

## Run

```
gcc -O2 main.c -o mnist -lm
./mnist
```
